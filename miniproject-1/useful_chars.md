# Some useful Unicode code points are:

Character |	Description |	Unicode |
--- | --- | --- |
|─|Horizontal line|	U+2500|
|│|	Vertical line|	U+2502|
|┌|	Top-left corner|	U+250C|
|┐|	Top-right corner|	U+2510|
|└|	Bottom-left corner|	U+2514|
|┘|	Bottom-right corner|	U+2518|
|├|	Left intersection|	U+251C|
|┤|	Right intersection|	U+2524|
|┬|	Top intersection|	U+252C|
|┴|	Bottom intersection|	U+2534|
|┼|	Four-way intersection|	U+253C|
